Вводная часть
Цель работы
Приобрести практические навыки по настройке динамического распределения IP-адресов
посредством протокола DHCP (Dynamic Host Configuration Protocol) в локальной сети.
Задание
1. Добавить DNS-записи для домена donskaya.rudn.ru на сервер dns.
2. Настроить DHCP-сервис на маршрутизаторе.
3. Заменить в конфигурации оконечных устройствах статическое распределение
адресов на динамическое.
4. При выполнении работы необходимо учитывать соглашение об именовании.
